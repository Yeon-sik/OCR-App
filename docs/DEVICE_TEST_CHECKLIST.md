# 실제 Android 기기 테스트 체크리스트

로컬 빌드나 UI 테스트 APK 컴파일은 이 체크리스트의 통과 증거가 아닙니다. 테스트 날짜, APK revision, 기기 모델, Android 버전을 별도 비공개 기록에 남깁니다.

## 설치와 구성요소

- [ ] `app-debug.apk` 설치 및 첫 실행
- [ ] Google Play Services가 있는 지원 기기에서 Document Scanner 시작
- [ ] 최초 scanner 구성요소 다운로드 상태 확인
- [ ] 오프라인/구성요소 미준비 시 크래시 없이 안내 후 재시도
- [ ] 지원하지 않는 기기에서 `unsupported` 처리

## 촬영과 이미지

- [ ] 카메라 자동 경계 검출
- [ ] 수동 경계 수정
- [ ] 원근, 회전, 명암/필터 보정 결과 확인
- [ ] 갤러리 이미지 선택
- [ ] 여러 페이지/긴 영수증 구간 추가와 순서 보존
- [ ] 중복 이미지 후보 경고, 자동 삭제·병합 없음
- [ ] 스캔 취소 후 빈 세션 정리
- [ ] 화면 회전/백그라운드 복귀 후 상태 확인

## OCR과 검수

- [ ] 한국어, 영문, 숫자가 섞인 합성/허가된 비공개 영수증 OCR
- [ ] block, line, element, bounding box 위치 연결 확인
- [ ] 이미지 확대와 bounding box overlay 정렬 확인
- [ ] 판매처, 날짜, 통화, 최종 합계 누락 표시
- [ ] 판매처명에서 지점명·고객센터·영업시간 등 옆 텍스트가 제외됨
- [ ] `GS THE FRESH`처럼 같은 행·같은 크기의 여러 단어 판매처명이 개별 단어로 잘리지 않음
- [ ] `OO점` 지점명, 공백/하이픈 변형 사업자등록번호, 도로명 주소 인식
- [ ] 날짜와 다른 OCR 행의 현지시각이 `purchase_local_time`으로 표시되고 offset은 추측하지 않음
- [ ] 최종 결제금액 또는 카드 승인금액 fallback이 채워지고 뒤쪽 카드번호를 금액으로 선택하지 않음
- [ ] `26, 760`처럼 쉼표 주변에 OCR 공백이 생긴 최종 결제금액을 `26,760`으로 복원함
- [ ] 원/₩/KRW 또는 한국어 결제금액 문맥에서 KRW가 채워지고 USD 등 외화 표기가 있으면 KRW를 추론하지 않음
- [ ] `과세물품가액`·`면세물품가액`만 있는 영수증의 세금 합계가 빈칸임
- [ ] `상품명`/`품명`, `단가`, `수량`, `금액` 표의 열 위치대로 상품 필드가 분리되고 옆 열 숫자가 상품명에 섞이지 않음
- [ ] 한 상품 행이 여러 OCR line/element로 갈라져도 상품명·merchant SKU·수량·단가·행 금액이 같은 행으로 결합됨
- [ ] 단가 열이 없는 `상품명`/`수량`/`금액` 표에서 단가는 빈칸이고 수량·행 금액은 유지되며 단가가 역산되지 않음
- [ ] 표 헤더 한 글자 오인식 또는 헤더 누락 시에도 보존식이 맞는 숫자 열만 단가·수량으로 배정됨
- [ ] 공백이 끼어 인식된 지점명·사업자번호·주소·구매시각·결제금액 라벨이 후보로 복구됨
- [ ] 포인트·회원번호·카드번호·사업자정보 행이 상품으로 생성되지 않음
- [ ] 이전 파서 세션 복원 시 재분석 안내가 표시되고, OCR 재실행 전 기존 사용자 수정은 보존됨
- [ ] 저신뢰 행 강조
- [ ] 상품/할인/세금/수수료/반품 유형 변경
- [ ] 상품명, merchant SKU, 수량, 단가, 행 금액 수정
- [ ] 잘못된 정수/수량 입력 거부
- [ ] 단가가 명시된 경우에만 수량 × 단가 보존식 차단
- [ ] source line reference 중복 차단
- [ ] 합계 차이 또는 명시적 사유 처리
- [ ] 검수 진행 표시(확인 완료 행 수, 차단·경고 건수)가 수정에 따라 갱신됨
- [ ] "확인이 필요한 N행만 보기" 필터가 저신뢰·차단 행만 남기고 나머지 행의 값을 바꾸지 않음
- [ ] OCR이 놓친 행을 직접 추가하면 `user_entered:` 표식과 "사용자 직접 입력" 표시가 나타나고, 경고는 뜨지만 확정이 차단되지 않음
- [ ] 안내문이 상품으로 인식된 행을 삭제할 때 확인 대화상자가 먼저 뜨고, 삭제 후 되돌리기로 금액까지 그대로 복구됨
- [ ] 되돌리기·다시 적용 후에도 수정 이력이 지워지지 않고 역방향 행이 추가됨
- [ ] 차액이 있을 때 원인 후보가 표시되고, 적용하기 전에는 어떤 값도 바뀌지 않음
- [ ] 후보를 적용한 결과가 사용자 수정으로 기록되고 확정 상태가 초안으로 되돌아감
- [ ] 실제 영수증에서 제시된 차액 후보가 원본 인쇄값과 일치하는 비율 기록

## 복구와 내보내기

- [ ] 이전 `0.1.2` 설치 위에 `0.1.5`를 업데이트해 Room v1→v2 migration 후 기존 세션·이미지·수정 이력이 유지됨
- [ ] 검수 중 앱을 강제 종료한 뒤 세션, 이미지, OCR 위치, 수정 이력 복원
- [ ] 검수 확정 후 재실행·내보내기 재시도에도 manifest `reviewed_at`이 실제 확정 시각으로 유지됨
- [ ] 초안 덮어쓰기 실패를 유도해도 직전 정상 JSON이 유지되고 다음 수정에서 저장을 재시도함
- [ ] draft JSON은 저장되지만 공유 버튼 비활성화
- [ ] 필수 검증 통과 후 `final` + `user_verified`
- [ ] 같은 검증본 재내보내기 시 revision/idempotency 동일
- [ ] raw text 공유 기본 제외
- [ ] raw text 포함 시 JSON 미리보기 경고와 실제 내용 일치
- [ ] Android 공유 시트가 `content://` JSON 하나만 받음
- [ ] 원본 이미지와 `ocr-debug.json`이 공유되지 않음
- [ ] 세션 삭제 후 DB metadata와 앱 전용 파일이 모두 사라짐
